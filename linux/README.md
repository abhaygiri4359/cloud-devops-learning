# Linux

This folder contains notes and hands-on practice from my Linux learning journey.

## What I'm learning

- Navigating the filesystem and managing files and directories
- Working with users, groups, ownership, and permissions
- Using processes, services, and system logs
- Managing software with package managers
- Exploring networking and troubleshooting connectivity
- Writing shell commands and basic scripts

## Useful commands

| Command | Purpose |
| --- | --- |
| `pwd` | Show the current directory |
| `ls -la` | List files, including hidden files, with details |
| `cd <directory>` | Change to a directory |
| `mkdir <directory>` | Create a directory |
| `cp <source> <destination>` | Copy a file or directory |
| `mv <source> <destination>` | Move or rename a file or directory |
| `man <command>` | Read a command's manual page |

## Practice

Try commands in a Linux environment such as a virtual machine, a container, or
Windows Subsystem for Linux (WSL). Check a command's manual page or help output
before using unfamiliar options.
